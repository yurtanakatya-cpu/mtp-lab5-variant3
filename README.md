## Запуск

Нужен Python 3.10 или новее с Tkinter. Сторонних пакетов нет:
`tkinter`, `sqlite3`, `decimal` и `unittest` входят в стандартную библиотеку.

Из корня проекта:

```bash
python main.py
```

Альтернативная точка входа:

```bash
python -m lab5_app
```

Проверить наличие Tkinter можно командой `python -m tkinter`.
В Windows Tkinter доступен в стандартной установке Python с компонентом
Tcl/Tk. Для запуска нужен графический рабочий стол. В Linux может
потребоваться системный пакет `python3-tk`.

По умолчанию приложение создаёт `data/tasks.db` **в каталоге проекта**,
независимо от текущего рабочего каталога. Можно указать другой файл:

```bash
python main.py --database data/demo.db
python main.py --help
```

Относительный путь после `--database` отсчитывается от текущего каталога.
Если файл уже существует, задачи из него загружаются при запуске.
Файлы баз данных и кеш Python исключены из Git. Готовая база в
репозитории не нужна: приложение само создаёт таблицу при первом запуске.

## Работа с приложением

### Калькулятор — среднее №3

Введите два числа, выберите `+`, `-`, `*` или `/` и нажмите «Вычислить».
В полях также работает Enter. Допускаются отрицательные числа,
пробелы по краям, точка и десятичная запятая.

Например, `0,1 + 0.2` даёт `0.3`, `6 / 3` даёт `2`.
При пустом вводе, нечисловом значении или делении на ноль сообщение
появляется под кнопкой; после исправления можно считать дальше.

Вычисления используют `Decimal` с точностью 28 значащих цифр, без `eval`.
Бесконечность и NaN запрещены. Длина одного числа ограничена 80 символами.
Периодические дроби округляются; очень большие и малые результаты
выводятся в научной записи. Переполнение диапазона Decimal обрабатывается
как ошибка ввода.

### Вкладки Notebook — среднее №5

В одном окне находятся «Калькулятор», «Цветная панель», «Кликер» и
«Задачи · SQLite». Переключение сохраняет состояние остальных вкладок.
Доступны мышь и сочетания Ctrl+Tab / Ctrl+Shift+Tab. Окно можно растягивать;
формы и таблица изменяют размеры вместе с ним.

### Цветная панель — среднее №9

Кнопка «Сменить цвет» циклически меняет **фон панели**:
голубой → зелёный → жёлтый → розовый → голубой.
Название цвета обновляется внутри панели. Каждый клик выбирает
следующий цвет, поэтому двух одинаковых цветов подряд нет.

### Кликер — повышенное №3

«Клик!» начисляет очки; сначала один клик приносит одно очко.
Первое усиление стоит 10 очков, увеличивает силу клика на единицу
и удваивает цену следующего усиления. Следующие цены — 20, 40, 80 и т.д.
При нехватке очков кнопка покупки недоступна. Покупка списывает
стоимость из текущего счёта, отрицательный баланс невозможен.

Пример: 10 кликов → 10 очков → купить усиление → 0 очков,
сила клика 2 → ещё один клик → 2 очка.
«Начать заново» сбрасывает все три параметра.
Таймера нет; счёт живёт до закрытия приложения или сброса.

### Задачи SQLite — повышенное №7

1. Введите название, при необходимости отметьте «Выполнено» и нажмите
   «Добавить». Новая строка появляется в таблице и сразу сохраняется в БД.
2. Выберите строку. Название и отметка переносятся в форму.
3. Измените поля и нажмите «Сохранить» — обновится именно выбранный ID.
4. «Удалить» запрашивает подтверждение. Отмена сохраняет строку.
5. «Снять выбор» очищает форму. «Обновить» перечитывает данные из файла.

Название — от 1 до 120 символов после удаления крайних пробелов,
без переносов строк. Одинаковые названия разрешены: записи различаются ID.
Кнопки сохранения и удаления недоступны без выбранной строки.
Повторное открытие приложения сохраняет названия, отметки и удаления.

Таблица `tasks`:

| Поле | Назначение |
| --- | --- |
| `id` | `INTEGER PRIMARY KEY AUTOINCREMENT`, идентификатор |
| `title` | `TEXT NOT NULL`, название длиной 1–120 символов |
| `done` | `INTEGER NOT NULL`, 0 или 1, по умолчанию 0 |

Значения передаются в SQL через `?`. Имена таблицы и колонок постоянны.
Каждое изменение выполняется в транзакции, соединение закрывается после
операции. Ошибка SQLite показывается в статусе вкладки; неудачное чтение
оставляет прежние строки на экране. При ошибке открытия базы на старте
появляется диалог, программа завершается с кодом 1.

Это локальный список задач с фиксированной схемой, без миграций и
синхронизации. Если другой экземпляр удалил выбранную запись, сохранение
сообщит, что задача не найдена; список можно перечитать кнопкой «Обновить».

## Проверки

Из корня проекта:

```bash
python -m unittest discover -s tests -t . -v
```

Из другого каталога укажите абсолютные пути к `tests` и корню проекта
в параметрах `-s` и `-t`. Тестовый пакет содержит `tests/__init__.py`.

30 тестов проверяют четыре операции, ошибки ввода, округление, правила
кликера, полный CRUD, повторное открытие SQLite, кириллицу, кавычки и SQL
в названии, граничную длину, ошибки ID и отметки выполнения.
Интеграционные тесты создают настоящие виджеты Tkinter и вызывают кнопки:
проверяют переключение вкладок, смену фона, восстановление после ошибки,
покупку усиления, запись в БД и отмену удаления.
SQLite-ошибки в интерфейсе отдельно моделируются через `unittest.mock`.
Также проверяются справка, запуск скрипта из другого каталога и
размещение основных элементов в видимом окне минимального размера.

Для GUI-тестов нужен доступный дисплей; без него они не пропускаются,
а завершаются ошибкой. Тесты используют временные базы и не меняют
пользовательский `data/tasks.db`.

Проверено на Windows, Python 3.12.14 и Tcl/Tk 8.6.12: 30 тестов проходят.
Для ручной проверки откройте каждую вкладку, выполните примеры выше,
затем закройте и снова откройте приложение с тем же файлом базы.
Скриншоты интерфейса в репозиторий не включены.
